# Website

This folder is the website for Don't Even Bother: Pure Evil Edition. Vercel deploys it automatically
whenever a change to `main` is pushed to GitHub.

- `index.html`: the landing page
- `play/index.html`: the page that scales the game to fit the window
- `play/game.html`: the game and its loading screen
- `play/deb-v18.tar.gz`: the browser build of the game (Pygbag)

Live site: https://dont-even-bother.vercel.app/
